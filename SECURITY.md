# Security policy / 安全策略

Only the latest `main` revision is supported. This project is an engineering
prototype, not a certified ophthalmic or medical device. Its outputs must not be
used directly for diagnosis, prescription, manufacturing acceptance, or other
safety-critical decisions. / 仅支持 `main` 最新版本。本项目是工程原型，不是经
认证的眼科或医疗设备；输出不得直接用于诊断、验配、制造验收或其他安全关键决策。

Report vulnerabilities privately through GitHub's **Security → Report a
vulnerability** flow. Include the affected version, input type, backend,
reproduction steps, and impact. / 请通过 GitHub 私密漏洞报告渠道提交，并提供版本、
输入类型、后端、复现步骤与影响。
